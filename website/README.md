
# Prominent Hearts Website

Owned by All Prominent Ghana Limited.

## Technology
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Run locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

http://localhost:3000

## Production build

```bash
npm run build
```

## Vercel deployment

Connect this GitHub repository to Vercel.

Set the Root Directory to:

```text
website
```

Framework Preset: Next.js

Build Command:

```text
npm run build
```

## Important

The current homepage uses demonstration profiles and local-only interactions.

Real member registration, authentication, profile management, matching, messaging and payments must be integrated before public launch.

All members must be adults aged 18 or older.
