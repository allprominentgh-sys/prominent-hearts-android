# PROMINENT HEARTS

Android mobile application.

Publisher: All Prominent Ghana Limited

## Technology
- React Native
- Expo
- TypeScript
- Expo Router

## Installation

npm install

## Start the application

npx expo start

## Android APK

npm install -g eas-cli

eas login

eas build:configure

eas build --platform android --profile preview

## Google Play Store

eas build --platform android --profile production

## Important

This is an early development prototype.
Sample profiles and interactions are demo data.
Production authentication, database, messaging,
verification and moderation must be implemented
before public release.

This project is separate from the existing website.
